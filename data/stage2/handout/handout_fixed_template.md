# 2단계 질문 생성 안내 (프롬프트 포함 묶음)

이 폴더는 Text-to-SQL 모델의 질문 데이터를 만드는 작업 묶음입니다. 배치 파일 하나에 프롬프트와 SQL <<BATCH_SIZE>>개가 함께
들어 있습니다. 이 안내만으로 끝까지 진행하고, 진행 중에 사람에게 묻지 않습니다.

```
README.md                          이 문서
sql/batch_01.txt ~ batch_<<LAST_BATCH>>.txt   배치 파일 (모두 SQL <<N_SQL>>개)
```

## 진행

1. `sql/batch_01.txt`부터 `batch_<<LAST_BATCH>>.txt`까지, **배치 파일마다 새 세션**을 엽니다. 이전 대화·메모리·다른 배치의 내용이
   이어지지 않는 세션입니다. 한 세션에서 여러 배치를 돌리지 않습니다.
2. 새 세션에는 배치 파일 내용 전체를 **고치지 않고 한 번에** 넣습니다. 여러 메시지로 나누지 않고, 앞뒤에 다른 말을 붙이지 않습니다.
3. 세션의 응답을 **고치지 않고** `responses/batch_NN.json`으로 저장합니다(번호는 배치 파일과 같게). ```json 코드 블록으로 감싸 온 것도 그대로 둡니다.
4. 응답이 JSON이 아니거나, 중간에 끊겼거나, 입력의 id가 빠졌으면 그 배치를 **새 세션에서 다시** 돌려 덮어씁니다.
   같은 배치가 세 번 연속 실패하면 그 배치는 비워 두고 `model.txt`에 적습니다.

## 하지 않는 것

- 질문을 직접 쓰거나 고치지 않습니다. 질문을 만드는 코드도 쓰지 않습니다. 질문은 배치를 받은 새 세션만 씁니다.
- 프롬프트를 고치거나 힌트·예시를 덧붙이지 않습니다.
- 다른 배치의 응답이나 기존 데이터를 새 세션에 보여 주지 않습니다.
- 웹 검색, 파일 첨부는 쓰지 않습니다.

## 돌려줄 것

이 폴더에 아래를 담아 보냅니다.

```
responses/batch_01.json ~ batch_<<LAST_BATCH>>.json
model.txt     모든 배치에 쓴 모델 이름·모드(추론 설정 포함), 새 세션을 연 방법, 작업 날짜, 다시 돌린 배치 번호와 사유
```
